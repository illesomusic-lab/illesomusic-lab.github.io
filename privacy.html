ThruLine Privacy Policy

Last updated November 5, 2026.

ThruLine is a personal app built and used by a single person, its developer. It is not distributed to the public and has no other users.

What ThruLine accesses

With the user's permission, ThruLine connects to the user's own Google account to:

  • Gmail: read-only search of messages (sender, subject, date, and a short preview). ThruLine never sends, deletes, or changes email.
  • Google Calendar: read events, and create events only when the user asks to schedule something.

How information is used

This information is used only to help the user plan and keep track of their own work and commitments inside the app. When the user talks with ThruLine's assistant, the relevant text, which can include email previews and calendar details, is sent to Anthropic's Claude API to generate a reply. It is used for nothing else.

Where information is stored

Information stays on the user's own devices and in the user's private iCloud account, which is used to sync between their iPhone and Mac. Sign-in credentials are stored in the device's secure Keychain. ThruLine has no server of its own.

Sharing

ThruLine does not sell, share, or transfer user data to anyone, does not use it for advertising, and does not use it to train AI models. Information is passed to Anthropic only as described above, to generate the assistant's replies.

ThruLine's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The user can disconnect any account in ThruLine's Settings at any time, or revoke access from their Google Account's security settings.
